Batch signature of Signer documents with Web PKI

Choose the PDFs you want to sign (you can add as many as you want, in as many rounds as you want) and select a certificate. When you click "Sign Batch", the files are created as documents on Lacuna Signer as public signatures for the selected certificate's holder and signed in batch: for each document the browser starts the signature (getting the hash from Signer), signs the hash with Web PKI and notifies Signer that the signature is complete. The certificate stays selected, so you can add more files and sign again.
