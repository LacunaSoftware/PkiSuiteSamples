Batch signature of Signer documents with Web PKI

You sign every document now, in batch. Each document then follows its own flow on Lacuna Signer, waiting for its second signer.

Choose the PDFs you want to sign (you can add as many as you want, in as many rounds as you want), tell us who signs each one after you and select a certificate. When you click "Sign Batch", each file becomes a document on Lacuna Signer with a two-step flow -- you at step 1, the informed participant at step 2 -- and your signature of every document is performed in batch with a single confirmation on Web PKI: for each document the browser starts the signature (getting the hash from Signer), signs the hash with Web PKI and notifies Signer that the signature is complete. Signer then notifies each second signer. The certificate stays selected, so you can add more files and sign again.
