PKI Suite Samples

Digital signatures and certificate authentication with Lacuna Software's PKI Suite, from an ASP.NET Core server and an Angular app. In the browser, Web PKI reads the user's certificates and signs with their private key, which never leaves the user's computer. On the server, each task is done with PKI SDK (on this server) or with Rest PKI Core (Lacuna's cloud API).
