XML signature with PKI SDK

Signs a whole XML document with an enveloped XAdES signature. The server uses PKI SDK, and Web PKI signs with your certificate in the browser. The sample document has a signaturePlaceholder element where the signature goes; other documents get it at the end of their root element.
