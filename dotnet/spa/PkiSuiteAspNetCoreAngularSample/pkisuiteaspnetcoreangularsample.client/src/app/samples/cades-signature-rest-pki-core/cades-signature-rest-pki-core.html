CAdES signature with Rest PKI Core

Signs any file, producing a CMS signature (a .p7s file that contains the signed file). The signature is computed by Rest PKI Core, Lacuna's cloud API. This sample signs new documents only: Rest PKI Core has no option to co-sign an existing .p7s (the PKI SDK sample can).
