Timestamp a PDF with Rest PKI Core

Adds a document timestamp to a PDF: a timestamp authority attests that the PDF existed, exactly as it is, at that time. The server sends the PDF to Rest PKI Core, Lacuna's cloud API, which requests the timestamp and embeds it in the PDF. Nothing else in the PDF changes, and nobody signs it, so this sample does not use Web PKI.
