NF-e XML signature with PKI SDK

Signs the infNFe element of a Brazilian electronic invoice (NF-e), following the NF-e national standard. The server uses PKI SDK, and Web PKI signs with your certificate in the browser. Rest PKI Core has no options for NF-e signatures, so this task has no Rest PKI Core sample.
